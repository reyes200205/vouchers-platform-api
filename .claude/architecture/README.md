# Architecture

Esta carpeta concentra decisiones arquitectónicas del proyecto Mis vales.

## Contenido esperado

- Decisiones de capas y límites del dominio.
- Flujos de negocio end-to-end.
- Diagramas conceptuales de crédito, relaciones y conciliaciones.
- Criterios para motor financiero, puntos, auditoría y autorizaciones.
- Reglas sobre qué vive en backend, frontend, dominio, persistencia y documentación.

## Cómo usar esta carpeta

- Captura aquí las decisiones que no deberían perderse entre conversaciones.
- Usa diagramas o notas cuando una regla tenga varios actores o varios estados.
- Registra los puntos donde un cambio requiere migración, versionado o impacto en datos activos.

## Regla

La arquitectura debe reflejar el negocio financiero, no solo la tecnología usada para implementarlo.
